# Буксир — генератор фирменной графики

Открыть: `Buksir.html` (работает без интернета, нужен только для шрифтов интерфейса). Онлайн-версия опубликована артефактом.

## Режимы

**Интерференция.** Два набора концентрических контуров (A и B) накладываются с вычитанием: где контуры пересекаются, остаётся фон. Отсюда шахматная интерференция, как на референсах. У каждого набора:

| Параметр | Что делает |
|---|---|
| Контуров | число колец в наборе |
| Ширина, Высота | размер самого внутреннего контура |
| Шаг по X, Шаг по Y | насколько каждый следующий контур шире и выше (с каждой стороны). Разный шаг даёт горизонтальный или вертикальный характер, разница в несколько пикселей между A и B даёт сетку |
| Толщина, Рост толщины | толщина контура и её прибавка от кольца к кольцу |
| Скругление | «в долях» (100 % = капсула) или «одинаковое» (радиус в пикселях у всех колец) |
| Центр X/Y | положение набора; тянется мышью прямо на макете, с Shift двигаются оба набора |
| Смещение X/Y | сдвиг центра от кольца к кольцу: кольца расходятся не из одной точки (арки, подъём) |
| Скорость | на сколько колец набор сдвигается за цикл анимации; минус — внутрь |

Наложение: вычитание (основной режим), поверх, только A, только B. Можно сделать наборы разного цвета.

**Фото в контурах.** Один набор контуров, в толщине каждого контура фото в своём масштабе: от центра к краю оно увеличивается на «рост к краю» за кольцо (минус — уменьшается). Между контурами фон или фото без масштаба, в центре — исходное фото.

**Шлейф.** Исходное фото в контейнере ставится в одну из девяти точек макета (или тянется мышью). Копии растут от точки роста по прямым: из угла — по диагонали, сверху — вниз, из центра — во все стороны. Задаются число копий, масштаб последней, шаг (ускоряется или ровный), какая копия сверху, пропорции и скругление контейнера, кадрирование фото внутри.

Общее: 6 форматов (1:1, 4:5, 9:16, 16:9, плакат A 1240 × 1754, баннер 1800 × 800), темы цвета и свои цвета, зерно, логотип (9 мест, вертикально, на плашке). Размеры хранятся в долях: короткая сторона макета = 1080 единиц, поэтому заготовки одинаково работают во всех форматах.

## Экспорт

- PNG ×1, ×2, ×3.
- SVG: контуры в кривых (в режиме вычитания одним путём с правилом even-odd), логотип отдельным путём. В режимах с фото фото вшито, каждая копия или кольцо — отдельная группа с обтравочным контуром.
- MP4 (H.264) и WebM (VP9) через WebCodecs, 25/30/60 к/с, 1–4 цикла. GIF 25 к/с, ×1, ×½, ×⅓.
- Анимация замкнута без шва: крайние контуры и копии плавно набирают и теряют толщину или прозрачность.

## Устройство

- `src/page.html` — разметка и стили интерфейса.
- `src/app.js` — вся логика: геометрия колец (`rings`), сцена (`buildScene`), отрисовка на холсте (`drawScene`), SVG (`sceneSVG`), панель, экспорт.
- `assets/logo.json` — логотип в кривых, обведён из `Refs/logo.png` скриптом `assets/trace.py` (potracer, запускать из корня папки).
- `vendor/` — mp4-muxer 5.2.2, webm-muxer 5.1.4 (минифицированы terser), gifenc 1.0.3. Все MIT.
- `build.py` → `Buksir.html` и `dist/artifact.html`.
- `test/` — стенды Playwright: `shots.js` (листы заготовок), `full.js` (кадр заготовки в полном размере), `check.js` (стык цикла, экспорт, телефон).

Порядок обновления: править `src/` → `python3 build.py` → проверить `Buksir.html` → опубликовать `dist/artifact.html` в тот же артефакт.
